# Changelog

## 1.0.0 - 2026-08-12

- First public Windows release of KareMetin.
- Offline Whisper Large v3 Turbo transcription with automatic CPU fallback.
- Native FFmpeg subtitle rendering, project packages, and terminal automation.
- English interface by default with an English/Turkish language selector.
- Editable `.karemetin` project files; legacy `.captionstudio` files remain importable.
